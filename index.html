Export your lifetime Piggycat

Downloads a piggycat-save.json file and creates a copyable save code. Keep it somewhere safe — it is your Piggycat backup. Anyone with the code can restore that Piggycat in their browser, so treat it like a house key.

Hosting this file on Netlify

This page is a single self-contained HTML file with no backend. To host it: go to Netlify → Add new site → Deploy manually, drag this index.html (in a folder, or zipped) onto the drop zone — done. Every visitor gets their own Piggycat in their own browser; saves don’t sync between people or devices unless they export/import above. Re-deploying a new file does not wipe a visitor’s Piggycat, because it lives in their browser, not on Netlify.

Import / restore a Piggycat

Paste a PC-SAVE-… code, or load a piggycat-save.json file. This replaces the Piggycat currently in this browser — export the current one first if you want to keep her.

Start again

Removes the Piggycat stored in this browser only so a fresh adoption can happen. Export first if she matters to you.
